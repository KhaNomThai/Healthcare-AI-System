8-class skin lesion classification (ISIC 2019) with ResNet50, EfficientNet-B3 and DenseNet121,
running entirely in the browser via ONNX Runtime Web. Images never leave the visitor's device.
For academic research and preliminary screening only. Not a substitute for diagnosis by a dermatologist.

Source: https://github.com/KhaNomThai/Healthcare-AI-System

Sample images: ISIC 2019 Challenge dataset (ISIC Archive), licensed CC BY-NC 4.0.
